二维输入不只是折线。 ReLU 把平面划成多个区域，每块内的映射都是仿射的；沿一条直线观察，结果才是连续的分段折线。

理解这张图

仿射层：z = W·x + b，可旋转、缩放、剪切和平移。严格的线性层对应 b = 0。

ReLU 层：逐坐标计算 max(0, z)。负值被压到 0，所以二维区域可能被压成一条线或一个点。

左图分区：颜色表示当前网络前缀中所有 ReLU 的激活模式。这些区域可能具有相同的最终映射，因此数量不一定等于最少仿射片数。数量只针对当前可见输入视窗。

右图：同色区域、网格与蓝色探针展示左图的映射。隐藏维度超过 2 时，仅显示前两个输出坐标；一维输出嵌入纵坐标为 0 的横轴。

手绘：函数模式按 x 排序；参数路径按绘制顺序，以累计弧长设定 t ∈ [−4, 4]。自由笔迹先简化为折线，构造网络在拐点之间精确一致，区间外按端点斜率延拓。参数网络的输入为 (t, 0)，第二个输入被忽略。

为什么要变宽：任意复杂折线未必能由固定宽度 2 的网络直接表示。构造采用 2 → N → 2，每个内拐点对应一个 ReLU 铰链，另用两个单元恢复带符号的线性项。

几何背景：Montúfar 等，On the Number of Linear Regions of Deep Neural Networks
